About This Project


Simple Accounting is a lightweight, responsive web application designed to help users track their daily income and expenses effortlessly. This project was developed as a final assignment for a Front-End Web Development course.


✨ Key Features:

  • Local Data Storage: All your records are securely saved in your browser's LocalStorage. No server or database is required, ensuring your financial data stays completely private on your device.
  • Dark Mode Toggle: A built-in interactive theme switcher. Your preference is remembered across all pages and sessions.
  • Real-time Summary: Automatically calculates your total balance, total income, and total expenses as you add new records.
  • Responsive & Accessible: Built with semantic HTML5 and fully responsive CSS. It works perfectly on both desktop and mobile devices, and includes screen-reader-friendly labels (ARIA attributes).

🛠️ Technologies Used:

HTML, CSS (Variables & Flexbox), Vanilla JavaScript (ES6).
